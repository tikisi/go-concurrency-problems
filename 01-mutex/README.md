# 読み取りの多いカウンタを RWMutex で守ろう

## 問題文
読み取りが多く、書き込みが少ない共有データでは、  
`sync.Mutex` だけでなく `sync.RWMutex` を使うことで、  
複数の読み取りを同時に実行できるようになります。

次の仕様を満たすプログラムを作成してください。

- 標準入力から 3 つの整数 `R`, `W`, `N` を読み込む
  - `R`: 起動する「読み取り専用 goroutine」の数
  - `W`: 起動する「書き込み goroutine」の数
  - `N`: 各書き込み goroutine がカウンタをインクリメントする回数
- 共有カウンタ（整数）を 1 つ用意する
- `W` 個の書き込み goroutine を起動し、それぞれが:
  - `N` 回ループし、毎回カウンタを 1 増やす
  - カウンタ更新時は `RWMutex` の「書き込みロック」を使って保護すること
- `R` 個の読み取り goroutine を起動し、それぞれが:
  - 合計で `N` 回カウンタを読み取る（ループ回数は自由に設計してよい）
  - 読み取り時は `RWMutex` の「読み取りロック」を使って保護すること
  - 読み取った値はどこかに使っても、捨ててもよい（最終出力に使わなくてよい）
- すべての goroutine（読み取り・書き込み）の終了を待ってから、
  カウンタの最終値を標準出力に 1 行で表示すること

期待される最終値は `W * N` となる。

> 実装のポイント:
> - 書き込み時: `Lock` / `Unlock`
> - 読み取り時: `RLock` / `RUnlock`
> を使い分けること。

## 入力
1 行に 3 つの整数 `R`, `W`, `N` が空白区切りで与えられる。

## 出力
すべての goroutine の処理が完了した後のカウンタの値を 1 行で出力せよ。
