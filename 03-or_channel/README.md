# orチャネルを実装せよ

## 問題文

複数の `done` チャネルを 1 つにまとめ、  
「**どれか 1 つでも close されたら、まとめたチャネルも close される**」ようにしたい。

このような振る舞いを持つ **orチャネル** を実装せよ。

次の条件を満たす関数 `or` を実装し、その動作を確認する簡単なプログラムを書きなさい。

```go
// 1つ以上の done チャネルを受け取り、
// そのどれか1つでも close されたら close されるチャネルを返す。
func or(channels ...<-chan struct{}) <-chan struct{}
```

要件
- len(channels) == 0 の場合は nil を返してよい（待ちようがないため）。
- len(channels) == 1 の場合は、その唯一のチャネルをそのまま返してよい。
- 2 個以上のチャネルが渡された場合、
    - 返り値のチャネルは どれか 1 つでも close された瞬間に close される こと。
    - それ以降はブロックせずに受信できるようになること。
- 実装にあたっては、必要に応じて goroutine を起動してよい。
