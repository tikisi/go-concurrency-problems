# チャネルによるパイプライン処理

## 問題文

チャネル・ジェネリクス・コンテキストを用いて、値を順に変換していく **パイプライン処理** を実装してください。

パイプラインは次の 3 つのステージ関数で構成されます。

1. `generator`
    - 可変長引数で渡された値の列を、チャネルに流すステージ
    - 入力: `ctx context.Context`, `vals ...T`
    - 出力: `<-chan T`
    - すべての値を送信し終わったらチャネルを `close` すること
    - `ctx.Done()` が閉じられたら、残りの値は送信せず、速やかに終了すること

2. `add`
    - 前段から受け取った値に「定数」を加算するステージ
    - 入力:
        - `ctx context.Context`
        - 入力チャネル: `<-chan T`
        - 加算する値: `v T`
    - 出力:
        - `<-chan T`
    - 入力チャネルが `close` されたら、出力チャネルも `close` すること
    - `ctx.Done()` が閉じられたら、処理を中断し、出力チャネルを `close` して終了すること

3. `multiply`
    - 前段から受け取った値に「定数」を乗算するステージ
    - 入力:
        - `ctx context.Context`
        - 入力チャネル: `<-chan T`
        - 乗算する値: `v T`
    - 出力:
        - `<-chan T`
    - 入力チャネルが `close` されたら、出力チャネルも `close` すること
    - `ctx.Done()` が閉じられたら、処理を中断し、出力チャネルを `close` して終了すること

ここで `T` は数値型を表す型パラメータとし、  
次の型制約インターフェース `Number` を定義して利用してください。

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```


## 入力
標準入力から次の形式で値を読み込む:

- 1 行目: 整数 N（入力列の長さ）
- 2 行目: N 個の整数 a_0, a_1, ..., a_{N-1}
- 3 行目: 加算に用いる整数 A
- 4 行目: 乗算に用いる整数 B
形式:
```
N
a_0 a_1 ... a_{N-1}
A
B
```

## 出力
最終的な出力は各`a_i`に対して以下を計算した値
```
(a_i + A) * B
```
