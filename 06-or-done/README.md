# or-doneチャネル

## 問題文
このパターンは、外部からのキャンセルシグナル（doneチャネル）を受け取りながら、値のチャネルからの読み込み処理を簡潔にするために使用されます。

or-doneチャネルパターンを実装するヘルパー関数`orDone`を作成します。
これを利用して、長時間実行される可能性のあるジェネレーター（generator）からの結果を安全に消費するプログラムを作成してください。  
`orDone`関数を使用することで、以下の2つの動作を一つの簡潔な`for range`ループ内で同時に処理できるようになります。
1. ジェネレーターから生成された値を順番に受け取る。
2. 外部から提供されたキャンセルシグナル（doneチャネル）を即座に検知し、安全に終了する。

目的: `orDone`ヘルパー関数を実装し、メインルーチンが結果を3つ受け取った後、残りの処理を待たずにジェネレーターをキャンセルして終了できることを証明すること。

## 入力
問題のコードには以下の要素を含みます。
1. `orDone`関数: 入力となる値のチャネル (c) とキャンセルチャネル (done) を受け取り、合成された値のチャネルを返す関数。
2. `generator`関数: 外部から停止シグナルを受け取ると、処理を中断する乱数ジェネレーター。
3. メインルーチン: generator を起動し、`orDone`を使って安全に結果を消費する。

## 出力
```
Received: [乱数1]
Received: [乱数2]
Received: [乱数3]
generator: Exited.
Done.
```
